# volei🏐 Vôlei: Paixão pela Quadra
📖 Sobre o projeto

Este projeto consiste em uma página informativa sobre o voleibol, apresentando sua história, principais regras, fundamentos e algumas curiosidades sobre o esporte.

A página foi desenvolvida como parte de um projeto acadêmico de desenvolvimento web, utilizando HTML5 e CSS3.

🎯 Tema

Voleibol

O site utiliza uma identidade visual baseada na cor roxa, criando uma aparência moderna e esportiva.
